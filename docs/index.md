# Getting started

**CurlyJSON** is a set of free JSON tools that run **entirely in your browser** — nothing you paste is uploaded. No sign-up, no pop-up ads.

## The tools

| Tool | What it does | Open |
|---|---|---|
| **JSON Formatter** | Beautify, minify, validate and repair JSON; tree view; AI explain | [curlyjson.com](https://curlyjson.com/) |
| **JSON Diff** | Compare two JSON documents — only real changes, array items matched by id | [/json-diff](https://curlyjson.com/json-diff) |
| **JSON to Code** | Generate types in 27 languages: TypeScript, Zod, Go, Python, Java, C#… | [/json-to-typescript](https://curlyjson.com/json-to-typescript) |
| **CSV & Excel** | JSON → CSV / Excel and back, with nested data flattened or rebuilt | [/json-to-csv](https://curlyjson.com/json-to-csv) |
| **YAML, XML & TOML** | Convert JSON to YAML, XML or TOML and back, with exact numbers and clear errors | [/json-to-yaml](https://curlyjson.com/json-to-yaml) |
| **JSONPath Playground** | Query JSON with standard RFC 9535 JSONPath, see every match and its path | [/jsonpath](https://curlyjson.com/jsonpath) |
| **JWT Decoder** | Decode JSON Web Tokens, read claims as dates, verify signatures | [/jwt-decoder](https://curlyjson.com/jwt-decoder) |

## Things that work everywhere

- **Paste, type, or drop a file** onto any input panel. Most tools also have an **Open** button.
- **Your last input is remembered** in your browser, so it's still there next time. **Clear** removes it.
- **Share links** put a compressed copy of your data *after the `#`* in the URL. Browsers never send that part to a server, so we never see it — but anyone with the link can.
- **Dark mode** follows your system; switch it with the sun/moon button in the header.
- **Big numbers stay exact.** IDs like `12345678901234567890` are never rounded, unlike most JSON tools.
