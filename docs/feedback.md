# Feedback & support

We read everything. Pick whichever is easiest:

## On GitHub

[Open an issue](https://github.com/AnjiOO7/curlyjson-docs/issues/new/choose) and choose:

- **Bug report** — something doesn't work or looks wrong.
- **Feature request** — an improvement to an existing tool.
- **New tool idea** — a JSON tool you'd like us to build.

You can also browse [existing issues](https://github.com/AnjiOO7/curlyjson-docs/issues) and add a 👍 to the ones you care about — we use that to prioritise.

## On Reddit

Ask questions, share tips and suggest tools in **[r/CurlyJSON](https://www.reddit.com/r/CurlyJSON/)**.

## By email

No GitHub account? Write to **[feedback@curlyjson.com](mailto:feedback@curlyjson.com)**.

## What helps us fix bugs quickly

1. Which tool and page (the URL).
2. What you did, what you expected, and what happened instead.
3. Your browser and operating system.
4. A **small example** that shows the problem — with any private data removed or replaced. Please **don't send real secrets or customer data**.
