# Keyboard shortcuts

All editors in CurlyJSON support these shortcuts. On Windows and Linux use <kbd>Ctrl</kbd> instead of <kbd>⌘</kbd>.

| Action | Shortcut |
|---|---|
| Search in the editor | <kbd>⌘</kbd> <kbd>F</kbd> |
| Find next / previous | <kbd>⌘</kbd> <kbd>G</kbd> / <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>G</kbd> |
| Replace | Open search (<kbd>⌘</kbd> <kbd>F</kbd>) — the panel has a replace field |
| Go to line | <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>G</kbd> |
| Undo / redo | <kbd>⌘</kbd> <kbd>Z</kbd> / <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> |
| Select all | <kbd>⌘</kbd> <kbd>A</kbd> |
| Indent / outdent selection | <kbd>Tab</kbd> / <kbd>⇧</kbd> <kbd>Tab</kbd> |
| Select next occurrence | <kbd>⌘</kbd> <kbd>D</kbd> |
| Fold / unfold block | Click the ▾ / ▸ arrow next to the line number |

> **Tip:** <kbd>Tab</kbd> indents inside the editor. To move focus out of an editor with the keyboard, press <kbd>Esc</kbd> then <kbd>Tab</kbd>.
